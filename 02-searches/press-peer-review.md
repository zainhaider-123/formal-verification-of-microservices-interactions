# PRESS 2015 Peer Review of Search Strategy

**Date:** 2026-03-12
**Reviewer:** Second information specialist (independent of search developer)
**Standard:** PRESS 2015 (McGowan J et al., J Clin Epidemiol 2016;75:40-46)

## PRESS 2015 elements assessed

### 1. Translation of the research question
**Comment:** PCC framework translated to three Boolean concept blocks.
The challenge is that "microservices" is commonly used, but
"modular monolith" has multiple spellings and the "consolidation" concept
is expressed many ways in practice. Approved with suggestions to broaden
Block 2.

### 2. Boolean and proximity operators
**Comment:** Boolean operators correctly used. Approved.

### 3. Subject headings (controlled vocabulary)
**Comment:** ACM CCS includes "Software architectures" but not specific
consolidation concepts. IEEE index terms include "Microservices" and
"Service oriented architecture." Free-text search is necessary given the
emerging nature of terminology. Approved.

### 4. Text word searching
**Comment:** Free-text search across title, abstract, and author keywords
appropriately covers terminology variation. Approved.

### 5. Spelling, syntax, line numbers
**Comment:** No spelling errors. Syntax correct for each database.
Approved.

### 6. Limits and filters
**Comment:** Date range 2020-2026 appropriate given topic emergence.
English-only and document type filters justified. CORE A*/A manual filter
applied post-retrieval is an acceptable trade-off. Approved.

## Suggestions adopted by search developer

1. **Add "modulith" to Block 2** — emerging shorthand for "modular
   monolith," particularly in Spring Boot / Java communities.
   **Adopted.**

2. **Add "architectural refactoring" to Block 2** — catches broader
   refactoring research where consolidation appears as a sub-case.
   **Adopted.**

3. ~~Remove "SOA" from Block 1~~ — **NOT adopted.** Some legacy
   consolidation cases involve SOA-to-monolith migration that is
   conceptually equivalent.

4. ~~Add "distributed monolith" to Block 2~~ — **NOT adopted.** This term
   describes a failure mode of microservices, not a consolidation target.

## Final approval

Search strategy approved for execution after the two adopted changes.
