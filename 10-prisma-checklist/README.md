## What is PRISMA 2020?

PRISMA 2020 is the most widely adopted reporting guideline for systematic
reviews. It consists of:

1. A 27-item checklist (with sub-items, 42 total reporting items)
2. A flow diagram template
3. An abstract checklist
4. Explanation and elaboration document

PRISMA 2020 is endorsed by:
- BMJ, JAMA, The Lancet, NEJM, PLOS Medicine
- Empirical Software Engineering (Springer)
- IEEE Software
- Journal of Systems and Software (Elsevier)
- Information and Software Technology (Elsevier)
- ACM Computing Surveys
- Many other journals across disciplines

## Why PRISMA 2020 alone (not Kitchenham, not Wohlin snowballing)?

This review uses PRISMA 2020 as the sole reporting guideline because:

1. It is the most widely accepted standard across disciplines.
2. The target venues (Empirical Software Engineering, IEEE Software) accept
   PRISMA 2020 without requiring additional SE-specific guidelines.
3. PRISMA 2020 is sufficient for methodological rigor when applied
   thoroughly.
4. A single guideline avoids ambiguity when multiple guidelines differ.
5. PRISMA 2020 is more recent (2020) than Kitchenham (2007) and reflects
   current best practices across disciplines.

For other valid options in SE reviews, we considered but did not adopt:

- **Kitchenham & Charters 2007/2015** — Historically dominant in SE. Does
  not contradict PRISMA 2020 but adds complexity by providing a second
  methodology lens. For this topic, PRISMA 2020 is sufficient.

- **Wohlin 2014 snowballing** — Recommended when database coverage of a
  topic is uncertain. Our pilot search found comprehensive coverage of the
  consolidation topic across six databases, so we accepted a slightly
  smaller corpus in exchange for stricter methodology.

Both would strengthen the review marginally but would not change the
fundamental conclusions.

## How to use this checklist

1. **At protocol stage:** Use the checklist as a planning aid — every item
   should be addressable in your protocol or planned for the manuscript.
2. **During the review:** Refer back to relevant items as you complete
   each methodological step.
3. **At manuscript drafting:** Map every item to a specific page or section.
4. **At submission:** Submit the completed checklist as a supplementary
   file alongside the manuscript.

Reviewers will check that every item has either a page number or a clear
"Not applicable" justification.
